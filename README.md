## About This Dataset

This repository contains tender and procurement data specifically for **Belgium**. The data is organized by industry sectors to help businesses, contractors, and suppliers find relevant opportunities efficiently.

### Sectors Covered

Each sector has its own branch with dedicated datasets:

- 🌾 **Agriculture and Food** - Tenders related to agricultural products, food supply, and farming equipment
- 💻 **Computer and Related Services** - IT services, software development, and technology procurement
- 🏗️ **Construction and Real Estate** - Building projects, infrastructure development, and real estate
- 🛡️ **Defence and Security** - Defence equipment, security services, and related procurement
- 🎓 **Education** - Educational services, supplies, and infrastructure
- ⚡ **Energy and Related Services** - Power generation, renewable energy, and energy infrastructure
- 🌍 **Environment and Sanitation** - Waste management, environmental services, and sanitation
- 💰 **Finance and Related Services** - Financial services, banking, and insurance
- 🔧 **Materials and Products** - Raw materials, manufactured products, and supplies
- ⛏️ **Mining and Ores** - Mining operations, mineral extraction, and ore processing
- 📰 **Printing and Publishing** - Printing services, publishing, and related media
- 📦 **Others** - Miscellaneous tenders not categorized above

## Dataset Structure

Each branch contains CSV/Excel files with tender information including:
- Tender ID
- Title and Description
- Deadline dates
- Purchaser details
- Value estimates (where available)
- Document links
- Sector classifications
